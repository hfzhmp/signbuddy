# SignBuddy

SignBuddy is an interactive web application designed to help users learn and translate sign language (ASL) using real-time hand gesture recognition. Built with modern web technologies and machine learning, SignBuddy aims to bridge the communication gap by making sign language learning accessible and engaging.

## 🚀 Features

- **Real-time Translation (`Terjemah`)**: translate hand gestures into text in real-time using your camera. Powered by TensorFlow.js and MediaPipe.
- **Smart Dictionary (`Kamus`)**: specific vocabulary with video examples to learn correct signing techniques.
- **Dual Language Support**: Switch between Indonesian and English for vocabulary validation.
- **Responsive Design**: Optimized for various screen sizes, ensuring a seamless experience on both desktop and mobile devices.
- **Interactive UI**: Smooth animations and transitons using Framer Motion.

## 🛠️ Tech Stack

- **Frontend Library**: [React](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [TailwindCSS](https://tailwindcss.com/)
- **ML Integration**: [TensorFlow.js](https://www.tensorflow.org/js) & [MediaPipe](https://developers.google.com/mediapipe)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📦 Installation

1.  **Clone the repository**

    ```bash
    git clone https://github.com/hfzhmp/signbuddy.git
    cd signbuddy
    ```

2.  **Install dependencies**

    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

## 📜 Usage

- Navigate to the **Home** page to learn about the project.
- Visit **Terjemah** to use the camera for real-time sign language translation. Ensure you grant camera permissions.
- Explore **Kamus** to browse the sign language dictionary.
